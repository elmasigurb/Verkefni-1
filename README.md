Café Website
============

A café website created with HTML and CSS as part of a web development project.

About the Project
-----------------

This project is a simple café website designed to present a welcoming and visually appealing online presence for a fictional café.

The website focuses on creating a warm and minimal café aesthetic while practicing basic HTML structure and CSS styling.

Technologies
------------

*   HTML
    
*   CSS
    

Features
--------

*   Responsive navigation menu
    
*   Café hero section
    
*   Coffee menu
    
*   Cold drinks menu
    
*   Product illustration
    
*   Background imagery
    
*   Responsive layout
    
*   Custom typography and styling
    
*   Responsive footer menu
    

Design
------

The website uses a warm, neutral color palette and café-inspired imagery to create a cozy atmosphere.

The design focuses on:

*   Typography
    
*   Color
    
*   Spacing
    
*   Alignment
    
*   Visual hierarchy
    
*   Layout
    
*   Consistency
    

What I Learned
--------------

Through this first ever HTML & CSS project, I practiced structuring a webpage using HTML and styling the layout with CSS. I focused on creating sections, positioning elements, working with typography and colors, and building a consistent visual style across the page.
